# Krossi iOS

iOS- ja Android-sovellus on **yksi Expo / React Native -koodipohja**, joka on toistaiseksi omassa
repossaan: `~/developer/krossi` (App Store: https://apps.apple.com/fi/app/krossi/id6771824274).
Expo rakentaa siitä sekä iOS- (`ios/`) että Android-version.

App Store -työ on lykätty — prioriteetti on nyt web (`../web`). Kun mobiilia jatketaan, koodipohja
siirretään tänne (`krossi/ios` + `krossi/android` jakavat saman lähdekoodin, joten käytännössä se
tulee kansioon `krossi/app/` ja nämä kansiot osoittavat sen natiiviprojekteihin).
